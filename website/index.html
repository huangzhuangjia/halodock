A FEW GOOD QUESTIONS

你可能还想知道。

支持哪些 Mac？+

当前发布的安装包适用于 Apple Silicon（M 系列芯片）Mac，需要 macOS 13 或更新版本。Intel 安装包暂未提供。

剪贴板会保存什么？+

只记录 App 运行期间新复制的文本和文件，最多 20 条；退出后清空，不上传服务器。目前不记录图片，一次复制多个文件只记录第一个，也会跳过超过 100 KB 的文本及带保密、临时、自动生成标记的内容。未带标记的敏感文本仍可能被记录。

为什么首次打开可能有安全提示？+

当前版本为 ad-hoc 签名，尚未经过 Apple Developer ID 签名与公证。如果系统阻止打开，请查看“系统设置 → 隐私与安全性”的对应提示。源码和每版 SHA-256 校验文件均在 GitHub 提供。

清空废纸篓需要什么权限？+

需要允许 HaloDock 通过“自动化”控制 Finder。首次确认清空时系统会请求授权；若已拒绝，App 提供“前往设置”入口。清空属于永久删除，操作前会再次确认。

如何更新和反馈问题？+

从 GitHub Releases 下载新版 DMG，退出旧版后替换安装。App 内“设置 → 软件更新”提供更新入口（v0.1.4 起）；v0.1.6 起支持 App 内显示进度并自动替换，完成后短暂重启。旧版首次升级到 v0.1.6 仍需手动安装。遇到问题请前往 GitHub Issues，附上 macOS、App 版本和复现步骤，截图前隐藏私人内容。
