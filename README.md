# HaloDock

原生 SwiftUI + AppKit macOS 状态栏工具。

## 当前功能

- 状态栏图标和中文 Popover
- 真实电池、内存占用、网络连接与硬盘可用空间，每 2 秒刷新
- 保持屏幕唤醒（IOPM assertion），关闭开关或退出进程后释放
- 区域截图并复制到剪贴板（系统截图工具）
- 专注模式的系统设置入口
- 运行期间的文本和文件剪贴板记录：最多 20 条，面板显示最近 3 条，点击重新复制
- 不记录带 Concealed / Transient / AutoGenerated 标记的内容；记录仅在内存中，退出后清空
- 主题跟随系统、浅色、深色；可选强调色；可配置存储卡片和剪贴板区域

网络只表示系统网络路径连接状态，不测量互联网可达性或速度。内存占用根据虚拟内存统计估算，不代表内存压力。无权限或读取失败显示不可用，不以示例数值替代。

## 构建与启动

```sh
swift build
./Scripts/build-app.sh
open .build/HaloDock.app
```

最低 macOS 13，当前构建产物为本机开发版本。

## DMG 安装包

```sh
./Scripts/build-dmg.sh
```

产物在 `dist/HaloDock-<版本>-macos-<架构>.dmg`，附带 SHA-256 校验文件。
打开 DMG，将 HaloDock.app 拖到 Applications；更新前先退出旧版，再替换应用。
图标由共享的“歪头屏”矢量生成。当前为 ad-hoc 签名，未进行 Developer ID 签名及 Apple 公证。

GitHub Releases 保存每版 DMG 和更新说明，Git 标签（如 `v0.1.0`）对应同版源码。
`dist/` 不纳入 Git 提交；二进制安装包作为 Release 附件管理。
